About this project

A CSC213 Discrete Structures group project that turns course registrations into a graph to find scheduling conflicts.

The idea

Each course is a vertex. Two courses are joined by an edge when at least one student takes both, so they must not run at the same time. Once the data is a graph, conflicts can be counted, listed and drawn.

How to use it

1. Add your courses with date, start and end time. 2. List each student and their courses. 3. Press Check clashes, then click any course in the timeline, graph or degree list to see its conflicts. 4. Open the Report tab to print or save the results as a PDF.

Discrete structures used

Sets hold each student’s unique courses. The graph G = (V, E) models conflicts. The adjacency list and adjacency matrix store them. The degree of a course is its number of conflicts, and the handshake lemma (degrees add up to twice the edges) checks the count. Graph colouring assigns time slots so that courses sharing students never share a slot.

Limitations

It finds conflicts and suggests slot groups but does not build a full timetable. Rooms and lecturer availability are not considered, each course has one session, and results depend on the data you enter.
